# Лендинг «Дом лесника» — дизайн (демо)

Дата: 2026-10-23. Статус: на согласовании.

## Цель

Демо-лендинг базы отдыха без бекенда: только дизайн и фронтенд. Содержание
общее для базы отдыха, под конкретную компанию не подгоняется.

Источники:
- `референс.jpg` (облако) — структура страницы и цветовая палитра.
- `анимация.mp4` (облако) — живая 3D-сцена «touch grass» для первого экрана;
  надпись «touch grass» заменяется на «Дом лесника».

Критерии готовности:
- первый экран — живая 3D-сцена, по центру «Дом лесника» шрифтом Poiret One;
- страница ниже повторяет структуру и палитру референса;
- плавный скролл на Lenis, анимации на GSAP (обязательно);
- `next build` проходит без ошибок, в консоли браузера нет ошибок;
- вёрстка работает на десктопе и на телефоне (от 360 px).

## Стек

- Next.js (App Router, TypeScript), `output: 'export'` → статическая папка `out/`.
- 3D: `three`, `@react-three/fiber`, `@react-three/drei`.
- Анимации: `gsap` (+ ScrollTrigger), `@gsap/react` (`useGSAP`).
- Скролл: `lenis` (`lenis/react`), синхронизирован с тикером GSAP и ScrollTrigger.
- Шрифты через `next/font/google`: Poiret One (заголовки, название),
  Lora (основной текст). Обе с кириллицей.
- Стили: CSS Modules + глобальные CSS-переменные палитры. Без Tailwind.

## Первый экран: 3D-сцена

Компонент `HeroScene` (клиентский, грузится через `next/dynamic` без SSR).

- **Небо:** сфера с шейдером-градиентом (зенит → горизонт), диск солнца/луны.
- **Облака:** `drei` `<Clouds>`/`<Cloud>`, медленно дрейфуют.
- **Холм:** широкая деформированная полусфера/плоскость, камера смотрит на
  вершину снизу, как в видео.
- **Трава:** `InstancedMesh` травинок (~60 тыс. на десктопе, ~20 тыс. на
  мобильных), свой шейдер: покачивание от ветра (шум по времени и позиции),
  травинки отклоняются от курсора (точка пересечения луча с холмом
  передаётся униформой), ночью вокруг курсора мягкое свечение.
- **Домик лесника:** низкополигональный, собран из примитивов (сруб, двускатная
  крыша, труба, крыльцо), тёплое окно (emissive), дымок из трубы (несколько
  полупрозрачных спрайтов).
- **Ели:** 5–7 штук из конусов разной высоты вокруг домика.
- **Камера:** лёгкий параллакс за курсором.
- **Время суток:** три пресета (цвета неба, солнце/луна, свет, туман, тон
  травы, яркость окна). Переход — твин GSAP за ~1.5 с. По умолчанию «день».
  Ночью: луна, звёзды, светлячки (`Points`), окно горит ярче.
- **Производительность:** DPR ≤ 1.75, меньше травинок на мобильных,
  рендер ставится на паузу, когда первый экран вне видимости.
- **Фолбэк:** без WebGL — CSS-градиент неба с силуэтом холма.
- **prefers-reduced-motion:** ветер слабее, без параллакса камеры.

Слой интерфейса поверх сцены:
- шапка: логотип «Дом лесника», меню (О нас, Домики, Активный отдых, Контакты),
  телефон-заглушка; при скролле вниз прячется, вверх — показывается;
- по центру: «Дом лесника» (Poiret One, крупно), подзаголовок
  «база отдыха · наедине с природой»;
- кнопки: «Забронировать» → `lenis.scrollTo('#contacts')`;
  «Подышать лесом» → интерфейс плавно скрывается (GSAP), сверху таймер 1:00
  и кнопка «вернуться», Lenis остановлен; по окончании или по кнопке всё
  возвращается;
- внизу: переключатель «день / закат / ночь»;
- нижний край — градиент в `--bg`.

Появление при загрузке: буквы названия, подзаголовок и кнопки въезжают
последовательно (GSAP timeline).

## Страница ниже первого экрана

1. **О нас** — три ряда «фото + текст» попеременно слева/справа, фото со
   скруглёнными углами. Через весь блок идёт плавная золотая SVG-линия,
   она прорисовывается по скроллу (ScrollTrigger scrub, `stroke-dashoffset`).
   Фото — лёгкий параллакс, текст — появление снизу.
2. **Выбери свой домик** — заголовок в две строки со сдвигом, как в
   референсе. Четыре карточки: А-фрейм, семейный дом, домик для двоих,
   большой корпус. В карточке: фото, название, вместимость, удобства
   (короткий список), цена «от … ₽/сутки», кнопка «Забронировать» → контакты.
3. **Активный отдых** — шесть плиток с фото: баня на дровах, лодка и
   катамаран, мангальная зона, рыбалка, лесные тропы, зимние забавы.
   Наведение — зум фото и подъём подписи.
4. **Контакты** (`#contacts`) — телефон и адрес-заглушки, часы связи,
   ссылки на соцсети (иконки, `#`), стилизованная SVG-карта-заглушка с меткой.
5. **Футер** — логотип, меню, © и пометка «демо».

Тексты — общие для базы отдыха, на русском.

## Проверка

- `npm run build` (статический экспорт) без ошибок и предупреждений TS.
- Playwright (headless Chrome, WebGL через SwiftShader): скриншоты 1440×900 и
  390×844, для дня/заката/ночи; проход скроллом до футера; консоль без
  ошибок; клики по меню и кнопкам ведут к нужным секциям; режим созерцания
  включается и выключается.
