# Лендинг «Дом лесника» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** демо-лендинг базы отдыха с живой 3D-сценой на первом экране и страницей в палитре референса.

**Architecture:** Next.js App Router со статическим экспортом. Первый экран — `<Canvas>` react-three-fiber (грузится только на клиенте) под слоем HTML-интерфейса. Состояние времени суток живёт в маленьком сторе (`timeOfDay.ts`), его читают и сцена, и интерфейс. Lenis управляет скроллом, GSAP/ScrollTrigger работают от его тикера.

**Tech Stack:** Next.js 16, React 19, TypeScript, three 0.186, @react-three/fiber 9, @react-three/drei 10, gsap 3.15 + @gsap/react, lenis 1.3, Vitest (юнит), Playwright (e2e и скриншоты).

**Spec:** `docs/superpowers/specs/2026-10-23-landing-design.md`

## Global Constraints

- Название на первом экране — ровно «Дом лесника», шрифт Poiret One.
- Палитра: `--bg #424123`, `--bg-deep #2E2D18`, `--line #E2BC8E`, `--heading #EFE3CC`, `--text #E3DAC4`, `--muted #A59B80`.
- Lenis и GSAP обязательны; любые скролл-анимации — через ScrollTrigger, синхронизированный с Lenis.
- `next.config.ts`: `output: 'export'`, `images: { unoptimized: true }`.
- Все тексты — на русском, общие для базы отдыха; все строки и данные карточек — в `content/site.ts`.
- Время суток по умолчанию — «день»; пресеты: `day`, `sunset`, `night`.
- Трава: 60 000 травинок при ширине ≥ 768 px, 20 000 — меньше; DPR ≤ 1.75.
- Без бекенда, без отправки форм, без Tailwind, без карты Obsidian.
- Коммиты от `Liotto1337 <egorstep.0801@gmail.com>` (глобальный git config), без строки `Co-Authored-By`.

4. **Быстрые переключения день → ночь → закат** до окончания перехода → сцена плавно идёт к последнему выбранному пресету, без зависаний на промежуточном. Юнит-тест в Task 2 (стор отдаёт последний `target`), твин с `overwrite: true` в Task 4.
